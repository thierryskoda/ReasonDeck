# Product

## Register

product

## Users

Mac users who switch AI models and reasoning effort frequently while working in a supported desktop app. They need a fast keyboard-first workflow that remains understandable and safe.

## Product Purpose

Provide a small local menu-bar utility for creating, editing, and removing model-and-reasoning keyboard shortcuts. Success means a user can complete permission setup from the Settings window, configure only the shortcuts they want, invoke them only while the assigned supported app is frontmost, and understand any failure without exposing chat or editor content or using a network service.

## Brand Personality

Native, restrained, trustworthy.

## Anti-references

Avoid a dashboard, power-user configuration language, decorative cards, custom visual controls where macOS already has a standard control, and hidden or silently repaired configuration.

## Design Principles

- Keep the main workflow visible and direct.
- Use familiar macOS interaction patterns.
- Make keyboard assignments explicit and conflict-free.
- Fail closed when configuration or the active target cannot be verified.
- Keep the product local-only and narrowly scoped.

## Accessibility & Inclusion

Use native keyboard navigation, VoiceOver labels, system colors, system typography, and macOS focus behavior. Do not rely on color alone. Support light and dark appearances and respect system accessibility settings.
